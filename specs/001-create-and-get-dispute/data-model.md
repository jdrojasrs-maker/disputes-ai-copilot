# Data Model: Create and Get Dispute

## Enums

**Reason** (`str` enum): `duplicate_charge`, `unrecognized_charge`, `product_not_received`,
`incorrect_amount`, `devolution`.

**DisputeState** (`str` enum): `open`. Other states and their transitions are added by a later
feature (constitution, principle II).

## DisputeCreate (request model)

| Field | Type | Rules | Spec |
|-------|------|-------|------|
| transaction_id | string | required, stripped, length 1 to 64 | FR-004 |
| customer_id | string | required, stripped, length 1 to 64 | FR-004 |
| amount | decimal | required, greater than 0, at most 2 decimal places, at most 12 digits in total | FR-002 |
| currency | string | required, matches `^[A-Z]{3}$` | Assumptions |
| reason | Reason | required, must be one of the enum values | FR-003 |
| description | string or null | optional, at most 1000 characters | FR-005 |

Model config: unknown fields are forbidden, so a request containing `state`, `id` or
`created_at` is rejected (FR-007).

## Dispute (stored and response model)

All `DisputeCreate` fields plus:

| Field | Type | Rules | Spec |
|-------|------|-------|------|
| id | UUID4 (string) | generated by the server, unique | FR-006 |
| state | DisputeState | always `open` at creation | FR-007 |
| created_at | datetime (UTC, timezone-aware) | set by the server | FR-008 |

The response returns the same data that was submitted (SC-005); `amount` is serialized as a
string.

## Repository interface

```text
DisputeRepository
├── add(dispute: Dispute) -> None
└── get(dispute_id: UUID) -> Dispute | None
```

`InMemoryDisputeRepository` keeps a dict keyed by id and exposes it as the public attribute
`disputes`, so tests can check that nothing was stored. A single instance lives for the app's
lifetime and is provided to routes through a FastAPI dependency so tests can replace or reset it.

## Errors

| Situation | HTTP | code |
|-----------|------|------|
| Invalid body, or malformed id in the path | 422 | `validation_error` |
| Well-formed id with no dispute, or an unknown route | 404 | `not_found` |
| Method not supported on a route (for example `PUT /disputes/{id}`) | 405 | `method_not_allowed` |

Body shape is defined in [contracts/disputes.openapi.yaml](contracts/disputes.openapi.yaml).

## State transitions

None in this feature. A dispute is created `open` and nothing changes it (FR-013).
